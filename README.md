### Shiroko7

Software engineer. This account is the side-project half — things built because
I wanted them to exist, not because anyone asked for them.

No deadlines here, which mostly shows up as a willingness to do the hard version
of a problem. Each README explains how the thing actually works, and what it
still gets wrong.

---

#### Tools

- **[dungeon-slop](https://github.com/Shiroko7/dungeon-slop)** — Dungeon generator and map editor with an AI architect that builds from your campaign notes. Bun + SQLite, deterministic generation, 1288 tests written as invariants rather than snapshots.
- **[phonetics-lab](https://github.com/Shiroko7/phonetics-lab)** — English pronunciation trainer. Bundled IPA dictionary, syllables and stress, recorded speech scored by distinctive features.
- **[chess-slop](https://github.com/Shiroko7/chess-slop)** — Analysis board with Stockfish 18 in a Web Worker. Hand-rolled UCI client.
- **[dice-slop](https://github.com/Shiroko7/dice-slop)** — Dice probabilities computed by convolution instead of simulated. Advantage as a CDF transform.
- **[earless-slop](https://github.com/Shiroko7/earless-slop)** — Click notes on a fretboard or piano, get the chord and scale names back.
- **[summarize-session-slop](https://github.com/Shiroko7/summarize-session-slop)** — Whisper plus a local model, turning session recordings into structured notes. Fully offline.

#### Game mods

- **[essence-dao-bg3](https://github.com/Shiroko7/essence-dao-bg3)** — Baldur's Gate 3 cultivation system. No dependencies, overwrites not one Larian file, installs mid-campaign.
- **[CoreKeeperDifficultyTuner](https://github.com/Shiroko7/CoreKeeperDifficultyTuner)** — Difficulty sliders that never write to your save. Stateless damage scaling, server-authoritative in multiplayer.
- **[CoreKeeperCombatMeter](https://github.com/Shiroko7/CoreKeeperCombatMeter)** — SKADA-style combat meter for co-op, with automatic boss encounter tracking.

#### Virtual tabletop

- **[master-loot](https://github.com/Shiroko7/master-loot)** — Owlbear Rodeo extension for WoW-style looting, with handouts rendered on aged paper.
- **[vessel](https://github.com/Shiroko7/vessel)** — Live submarine damage schematic, synced across every client at the table.
- **[essence-talent-system](https://github.com/Shiroko7/essence-talent-system)** — Reference for a homebrew 5e cultivation system. Markdown is the source of truth; the site is generated from it.
